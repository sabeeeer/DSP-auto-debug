# dq / abc 变换（Clarke / Park / InvPark）规范

Clarke（abc→αβ）、Park（αβ→dq）、InvPark（dq→αβ）、InvClarke（αβ→abc）四个环节。
本页是**验收判据 + 踩坑记录**；实现可自研，也可复用 TI DMC 库（须按第三节补偿）。

---

## 一、硬规则（逆变器 / 并网电压定向）

三相对称输入 `Va = A·sinθ`、`Vb = A·sin(θ−120°)`、`Vc = A·sin(θ+120°)`，θ 与 a 相同步时：

| 检查项 | 期望 | 不满足的后果 |
|---|---|---|
| 正变换 **d** | **= A（相电压幅值）** | 幅值跑到 q 轴 → 电压定向错、Vref 对比错 |
| 正变换 **q** | **= 0** | 残差非零 → 角度未对齐或正反系数不配套 |
| 反变换 | 由 `d = A, q = 0` 能**复原三相** | 幅值/相位错 → 占空比错 |
| 正反变换 | 必须**成对配套**（见第二节） | 混用 → 输出差 √(3/2)=1.2247 倍，PI 必跑偏 |

> **★门禁：`d ≠ 幅值` 或 `q ≠ 0` 时，禁止进入闭环 / 禁止发波（`vCL_LoopEnter()` 应先校验）。**
>
> 电机 FOC 是例外：那套惯例是 **q 轴 = 转矩轴（主控制量）**、d 轴给励磁，幅值落 q 轴属正常。
> 本规则只针对**逆变器/并网电压（或电流）定向**。

## 二、两套合法系数（选一套，不可混搭）

| | 正变换 Clarke（αβ） | 反变换 InvClarke（abc） | 功率算式 |
|---|---|---|---|
| **等幅值**<br>（MATLAB `abc_to_dq0`、本工程） | `α = Va`（等价 `(2/3)(Va−0.5Vb−0.5Vc)`）<br>`β = (Va + 2Vb)/√3` | `A = α`<br>`B = −0.5α + (√3/2)β`<br>`C = −0.5α − (√3/2)β` | `P = 1.5(vd·id + vq·iq)` |
| **等功率**<br>（TI/MTG 部分实现） | `α = √(2/3)·Va` (1.2247·Va)<br>`β = √(1/2)(Va + 2Vb)` | `A = √(2/3)·α` (0.8165·α)<br>`B = −√(1/6)α + √(1/2)β`<br>`C = −(A + B)` | `P = vd·id + vq·iq` |

**互逆校验（必做）**

```
等幅值：α = (2/3)(Va − 0.5Vb − 0.5Vc) = (2/3)(1.5Va) = Va  →  A = α = Va ✓
等功率：α = 1.2247·Va                                      →  A = 0.8165α = Va ✓
```

**Park / InvPark 必须同一角度约定**

```
Park   ：d =  α·cosθ + β·sinθ      InvPark：α = d·cosθ − q·sinθ
         q = −α·sinθ + β·cosθ              β = d·sinθ + q·cosθ
```

## 三、TI 库的坑（实测，MTG_CtrlInterFace.c）

TI 经典 DMC 的 `clarke_calc` + `park_calc` 直接吃 θ 时：**`Ds = 0`、`Qs = −A`（幅值落 Q 轴）** ——
它是为**电机 FOC** 设计的。用于逆变器电压定向时，必须补偿 90°：

```c
/* Park / InvPark 的角统一减 90° → 幅值搬回 d 轴 */
TiPark.Angle    = fTheta - 1.5707963f;    /* θ − π/2 */
TiInvPark.Angle = fTheta - 1.5707963f;    /* 与正变换配对，两处都要 */
```

其他注意：

- TI/MTG 的 `clarke_calc` 是 **等功率**（1.2247 / 0.7071 / 1.4142），其 `invClarke_calc` 用 **0.8165 / 0.4082 / 0.7071** 配套 ✓ —— **等功率下的参数不能照抄到等幅值工程**（差 1.2247 倍）。
- 只改正变换、忘记改反变换 → 单独看 dq 是对的，输出幅值却差 √(3/2) 倍，现象是"闭环稳不住/输出偏大"。

## 四、上电自检（建议做成门禁）

单位幅值、θ = 0 的测试向量（`Va=0, Vb=−0.866, Vc=+0.866`）：

```c
float fD = 0.0f, fQ = 0.0f;

vCL_DQ_AbcToDq(0.0f, -0.866f, 0.866f, 0.0f, &fD, &fQ);

/* 期望：fD ≈ +1.000，fQ ≈ 0.000
 * 不满足 → 不得进入闭环 / 发波 */
```

手工验算：`α = 0`，`β = (0 + 2×(−0.866))/1.732 = −1.0`；
Park(θ−90°) 的 `cos=0, sin=−1` → `d = 0·0 + (−1)(−1) = 1`，`q = −0·(−1) + (−1)·0 = 0` ✓

反变换回环校验（`d=A, q=0, θ=0` 应得 `Va=0, Vb=−0.866A, Vc=+0.866A`）：

```c
vCL_DQ_DqToAbc(1.0f, 0.0f, 0.0f, &fA, &fB, &fC);   /* 期望 A≈0, B≈−0.866, C≈+0.866 */
```

## 五、常见症状对照

| 现象 | 先查 |
|---|---|
| `fVd ≈ 0`、`fVq ≈ −幅值` | 幅值落 Q 轴（TI 原版未补偿 90°，或 θ 定义不同） |
| `fVd ≈ 幅值` 但 `fVq ≠ 0` 且随 θ 摆动 | 正反变换角度不一致，或 Clarke/Park 系数混搭 |
| dq 看着对，输出幅值却大/小 1.2247 倍 | 正变换等功率 + 反变换等幅值（或反之） |
| 闭环稳态 `fVd` 与 `Vref` 差 1.2247 倍 | 同上；或 Vref 生成走了另一套系数 |
| 三相输出相位错 120° 或反相 | InvClarke 的 B/C 顺序写错，或 β 符号约定不一致 |
